# JPROn't releases

Installers and SHA-256 checksums for JPROn't. The app checks this repository's latest release on start and offers to install newer versions after verifying the checksum. Source code is in private repositories.

## Download

**[Download JPROn't 1.7.0 for Windows (installer)](https://github.com/wilfrombdn/JPROnt-releases/releases/download/v1.7.0/JPROnt-Setup-1.7.0-win-x64.exe)**

- Windows 10 or 11, 64-bit. Installs for the current user; no administrator rights needed.
- Checksum: [JPROnt-Setup-1.7.0-win-x64.exe.sha256](https://github.com/wilfrombdn/JPROnt-releases/releases/download/v1.7.0/JPROnt-Setup-1.7.0-win-x64.exe.sha256)
- The installer is unsigned, so Windows SmartScreen may warn. Choose More info, then Run anyway.
- You also need the adapter manufacturer's RP1210 driver installed on the computer.
- All versions and release notes: [Releases](https://github.com/wilfrombdn/JPROnt-releases/releases)
